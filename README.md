# VibeTalk — ИИ-тренажер английского языка в Telegram

Telegram-бот для изучения английского языка через ролевые диалоги с ИИ.

## Возможности

- 👨‍🏫 Режим Учителя — исправляет ошибки и объясняет правила
- 🤝 Режим Друга — свободное общение без исправлений
- 📊 Уровни A1–C1 — адаптация сложности языка
- 🎭 Готовые сценарии — Travel, Study, Fun, Free Talk
- 🎲 Случайный сценарий — неожиданные ролевые ситуации
- ✍️ Свой сценарий — создай уникальную ситуацию
- 📚 Словарик — сохраняй новые слова из диалогов

## Установка

1. Склонируй репозиторий:
   git clone https://github.com/frikle/VibeTalk.git
   cd VibeTalk

2. Создай файл .env:
   copy .env.example .env

3. Заполни .env своими ключами:
   BOT_TOKEN=токен_от_@BotFather
   GROQ_API_KEY=ключ_от_console.groq.com

4. Установи зависимости:
   pip install -r requirements.txt

5. Запусти бота:
   python bot.py

## Использование

1. Открой бота в Telegram
2. Отправь /start
3. Выбери режим, уровень и тему диалога
4. Пиши на английском — ИИ ответит и исправит ошибки
5. Чтобы сохранить слово — сделай Reply на сообщение бота и напиши слово
